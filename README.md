# ATMOCE Product Website

A responsive product catalogue built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. No npm install or build command is required.

## Features
- Responsive ATMOCE-style landing page
- Kitchen Appliances listed before Home Appliances
- Product cards with product names and visual placeholders
- Product detail modal and unique product hash links
- Slide-in mobile menu with category accordions
- Search products by name/category
- About section and footer

## Product images
The current project uses styled product visual placeholders. Replace each product's `icon` in `script.js` and the `.product-image` markup in `cardTemplate()` with your official product image paths when available. Example: `assets/induction.jpg`.
